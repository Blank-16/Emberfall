# Emberfall

Emberfall is a 2D top-down action-RPG built around a decoupled architecture that seamlessly blends the **Phaser 3** physics and rendering engine with a highly reactive **React** HUD.

## Features

- **Data-Driven Architecture:** All weapons, enemies, bosses, and dungeons are strictly defined via JSON schemas (`src/game/data/`), which are comprehensively validated at load time to ensure referential integrity.
- **Decoupled Engine & UI:** Communication between the game world and the React HUD relies exclusively on an event-driven `EventBus` and `GameBridge`, ensuring thread-safe state management without direct DOM or Scene mutations.
- **Dynamic Combat System:** Features distinct attack phases (windup, active, recovery), weapon swapping mechanics, dodging with i-frames, and dynamic hit-stop freeze frames on critical strikes for enhanced game feel.
- **Procedural Asset Pipeline:** Dungeon maps are rapidly authored in ASCII and compiled dynamically to Tiled JSON at build time. Visual assets are procedurally generated at runtime (serving as structural placeholders for Phase 2 spritesheet integration).

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation & Execution
```bash
npm install
npm run dev
```
This will launch the Vite development server (typically at `http://localhost:5173/`).

*Note: The `npm run dev` and `npm run build` commands automatically execute `tools/build-maps.mjs` first, which dynamically compiles the hand-authored ASCII room layouts into valid Tiled JSON.*

## Controls

| Action | Keyboard | Gamepad |
|---|---|---|
| **Move** | WASD / Arrows | Left Stick / D-Pad |
| **Aim** | Mouse | Right Stick |
| **Attack** | J / Space / Left Click | A / R2 |
| **Dash** | Shift / K | B / L2 |
| **Swap Weapon (hold)** | Q | L1 / R1 |
| **Use Potion** | F | Y |
| **Interact** | E / Enter | X |
| **Pause** | Esc / P | Start |

*Weapon swapping requires holding the input for ~130ms to prevent accidental combo triggers. Swaps are rejected during active hit frames and will only execute during weapon recovery.*

## Project Structure

- `public/maps/`: Compiled Tiled JSON maps generated by the build tools.
- `src/game/`: Core Phaser 3 engine, including entities, combat systems, AI state machines, and world generation.
- `src/ui/`: React components handling the HUD, inventory, and pause menus.
- `tools/`: Utility scripts for map authoring (`author_rooms.py`) and compilation (`build-maps.mjs`).

## Roadmap

This repository currently encompasses **Phase 1 (Vertical Slice)**, which includes the complete foundation systems and the fully playable "Emberfall Grove" dungeon. 

**Phase 2** (In Progress) will introduce:
- Dungeons 2 and 3
- Upgrade Shops & Meta-Progression
- Cloud Persistence (via Supabase) and LocalStorage fallback
- Replacement of procedural runtime textures with Kenney CC0 spritesheets
